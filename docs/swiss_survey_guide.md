# Інструкція з навчання та роботи Swiss Survey Agent (vydra-swiss-survey)

> [!NOTE]
> Ця інструкція описує повний алгоритм роботи системи автоматичного та напів-автоматичного проходження опитувань на сайті **meinungsplatz.ch** з використанням проксі у Швейцарії, інтеграції Telegram-бота, штучного інтелекту Gemma 3 4B та Human-in-the-Loop панелі Astryx.

---

## 📐 Графічна схема архітектури та обміну даними

```mermaid
sequenceDiagram
    autonumber
    actor TG as 📱 Telegram Bot
    participant Web as 🌐 Astryx UI (Port 5005 / HTTPS)
    actor Human as 👤 Користувач / Адмін
    participant Agent as 🤖 Gemma 3 4B (Termux)
    participant Graph as 🧠 Persona Graph (SQLite)
    participant Chrome as 🖥️ Chrome CDP + SOCKS5 CH

    TG->>Web: 🔔 Сповіщення (=🔔 Нове завдання для Арсена / Олени)
    Web->>Web: ⏳ Запуск 10-хв відліку (waiting_auth)
    alt Людина підключається вчасно
        Human->>Web: ⚡ Натискає "Авторизувати та Запустити"
    else 10 хвилин вичерпано
        Web->>Agent: 🚀 Автоматичний запуск (Background)
    end

    Agent->>Chrome: Вхід через швейцарський проксі (100.66.97.93:1080)
    
    loop Кожен крок опитування
        Agent->>Chrome: Знімок екрана & Аналіз DOM
        Chrome-->>Agent: PNG Screenshot + DOM Tree
        Agent->>Graph: Запит відомих фактів (get_enhanced_persona)
        Graph-->>Agent: Зафіксовані правила (дохід, місто, стать)
        Agent->>Web: Публікація рішення (/api/survey/verify_step)
        
        opt Режим Навчання (Training Mode = ON)
            Web->>Human: ⏸️ Пауза: показує скріншот та пропозицію Gemma
            Human->>Web: ✏️ Затверджує або Коригує дію + Пояснення правила
            Web->>Graph: 💾 Запис нового правила у SQLite DB
        end
        
        Agent->>Chrome: Виконання кліку / введення тексту
    end

    Agent->>Chrome: Фіксація фінального екрана винагороди (CHF)
    Agent->>Web: ✅ Завершення опитування & Збереження доказів
```

## 🔄 Покроковий алгоритм роботи системи

```mermaid
flowchart TD
    A[🔔 Повідомлення від Telegram Бота] --> B[⏳ Start 10-Min Waiting Timer]
    B --> C{Людина натиснула 'Авторизувати'?}
    C -- Так --> D[⚡ Запуск негайно]
    C -- Ні (Таймаут 10 хв) --> D
    
    D --> E[🌐 Підключення Chrome через SOCKS5 CH Proxy]
    E --> F[🔐 Авторизація на meinungsplatz.ch]
    F --> G[📸 Скріншот сторінки & Аналіз Gemma 3 4B]
    
    G --> H{Режим Навчання увімкнено?}
    H -- Так --> I[⏸️ Пауза в Astryx UI]
    I --> J[👤 Перевірка людиною / Введення правила]
    J --> K[🧠 Запис у Persona Graph SQLite]
    K --> L[🖱️ Виконання дії в браузері]
    H -- Ні --> L
    
    L --> M{Екран Винагороди?}
    M -- Ні --> G
    M -- Так --> N[🎉 Фіксація винагороди CHF & Збереження скріншота]
```

## 📖 Як навчати агента в режимі Human-in-the-Loop:

1. **Перевірка режиму навчання:**
   Впевнитись, що в шапці Astryx UI увімкнено прапорець **"🎓 Режим Навчання"**.
2. **Отримання тригера:**
   При надходженні сповіщення від бота таймер починає відлік 10 хвилин.
3. **Авторизація:**
   Натиснути **"⚡ Авторизувати та Запустити негайно"** або дочекатися автоматичного старту.
4. **Перевірка дій:**
   На кожному кроці панель покаже скріншот та пропозицію Gemma:
   - Якщо Gemma відповіла правильно: натисніть **"✅ Затвердити рішення Gemma"**.
   - Якщо Gemma помилилась: введіть точну назву кнопки у поле виправлення, напишіть коротке пояснення правила (напр. *Для теми доходу вибирати вилку 60k-80k*) та натисніть **"🎓 Навчити Агента"**.
5. **Автоматичне збереження:**
   Усі нові правила миттєво зберігаються у базовий граф пам'яті (`~/.vydra-survey-profiles/survey_graph.db`) і будуть використовуватись агентом у майбутніх сесіях.
