# SDD у vydra-swiss-survey — Книга для оператора

> Ця книга пояснює, як влаштована Spec-Driven Development (SDD) система в
> проєкті `vydra-swiss-survey` — навіщо вона, як нею користуватись щодня, і
> як влаштована "під капотом" мультиагентна координація (Claude Code, Codex
> CLI, AGY). Написано після впровадження `specs/021-multiagent-sdd-extension/`
> (2026-08-17), відображає РЕАЛЬНИЙ стан репо, не задум.

## Зміст

1. [Навіщо SDD](01-navischo-sdd.md) — контраст із "vibe coding", роль оператора
2. [15-хвилинний Quickstart](02-quickstart.md) — покроковий приклад однієї фічі
3. [Креслення: Spec, Plan, Tasks, Конституція](03-slovnyk.md) — базовий словник
4. [Командна консоль](04-komandna-konsol.md) — що вводити, для кожного агента
5. [Передача контексту та ворота верифікації](05-handoff-gates.md) — мультиагентний протокол
6. [Архітектура: три шари SDD](06-arhitektura-shary.md) — конституція / методологія / транспорт
7. [Довідник та усунення несправностей](07-dovidnyk.md) — cheat sheet, глосарій, файлова карта

## Як читати

Розділи 1-3 — читай послідовно, вони дають контекст один одному (~30 хв).
Розділи 4-7 — довідникові, повертайся до них під час реальної роботи.

## Походження

Ця книга — підсумок сесії 2026-08-17, у якій `specs/021-multiagent-sdd-extension/`
(clarify → spec → plan → tasks, фази P0-P7) додав Codex CLI та формалізував
AGY-інтеграцію до вже наявної SDD-системи проєкту. Повні технічні деталі —
у `specs/021-multiagent-sdd-extension/plan.md`, тут — людський переклад.
