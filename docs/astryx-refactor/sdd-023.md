**Виконавець**: Claude Opus-субагент (Agent tool, `model: opus`, з gitnexus).
**Файли**: `survey_agent.py`, `cdp_client.py`, `astryx_survey_server.py`,

**Обов'язково**: `mcp__gitnexus__impact()` на кожен символ перед редагуванням
(та сама вимога, що діяла в 022). Кожен фікс — окремий комміт, поведінка
змінюється НАВМИСНО (на відміну від 022) — це і є мета Track A.

## Track B — UI defects (SurveyOps/Viewport, знайдено Lovable, 2/6 перевірено Claude)

**Виконавець**: AGY .234 (`--mode=accept-edits`).
**Файли**: `web/src/ops/Viewport.tsx`, `useViewportZoom.ts`, `AttentionCard.tsx`,
`ops/StepTimeline.tsx`, `screens/ops/SurveyOps.tsx`, `ui/primitives` (новий wrapper).

| # | Дефект | Перевірено Claude? | Що виправити |
|---|---|---|---|
| U1 | Zoom >100% не прокручується повністю | **ТАК, живо на проді**: `containerScrollWidth=1577` < реальна ширина трансформованого контенту `2160px` (bounding rect) на 270% zoom — правий край недоступний для скролу | `transform: scale()` не міняє layout-box для overflow. Задати внутрішньому блоку явний `width/height = 100% * (zoomPercent/100)` замість голого `transform: scale()`, АБО власний pan-стан (translate) замість покладання на `overflow-auto` браузера |
| U2 | Кнопка «✎ Виправити» у fullscreen — тихий no-op | **ТАК**: `SurveyOps.tsx:166` `onCorrect={() => handleAction('correct')}` без `correction`-аргументу, на відміну від коректного `SurveyOps.tsx:144` `onCorrect={(corr) => handleAction('correct', corr)}`. `handleAction`'s `correct`-гілка виконується лише `if (action === 'correct' && correction)` | Передати `corr` на обох call-sites (fullscreen-версія AttentionCard теж має відкривати форму корекції, не викликати `handleAction` напряму без даних) |
| U3 | Таймлайн фальшивий — усі кроки `status: 'success'` | не перевірено, довіра до Lovable-звіту (код читається однозначно) | `parsedSteps` в `StepTimeline.tsx`/`SurveyOps.tsx` має брати реальний статус кроку з логу/трейсу, не хардкодити `'success'` |
| U4 | `stepTotal` не передається у `Viewport` | не перевірено | Прокинути реальну загальну кількість кроків від `SurveyOps.tsx` до `Viewport`, замінити «Крок N» на «Крок N / M» |
| U5 | TextInput-контракт-хак розмазаний по 13 файлах | підтверджено в 021D (сам факт розповсюдження) | Один спільний wrapper у `web/src/ui/primitives` (напр. `useControlledValue`/`normalizeInputChange`), усі 13 файлів переходять на нього — інакше 14-й новий файл повторить той самий баг |
| U6 | Непослідовний Toast API (`toast()` vs `toast.show()`) | не перевірено | Один адаптер у `ui/primitives`, усі виклики через нього |

**Обмеження**: `bin/ui_verify.sh` поріг `style={{ <= 17` лишається чинним.
U1 (pan/scroll rewrite) — найризикованіша зміна цього треку, тестувати живо
через CDP на дев-сервері перед комітом (той самий live-метод, що довів баг).
