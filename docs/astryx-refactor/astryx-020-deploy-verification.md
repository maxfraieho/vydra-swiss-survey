### Діагноз

Код 020 у гілці є (коміт `a73381b`), але задеплоєний `web/dist` зібраний **не з нього**:
або білд ішов зі stale-стану / іншої гілки, або нові компоненти
(`ops/Viewport.tsx`, `useViewportMode.ts`, новий SideNav) **не підключені в `main.tsx`** —
файли існують, але жоден маршрут їх не імпортує. Тому `ui_verify.sh` (граматика по файлах)
проходить, а користувач бачить старий UI. Це дірка в самому гейті.

### Наслідок для методики

`bin/ui_verify.sh` перевіряє лише *наявність* файлів і відсутність HEX. Він не перевіряє,
що код **досяг екрана**. Потрібен runtime-гейт проти живого URL (див. `bin/deploy_verify.sh`
у промті 020-C), інакше кожен наступний звіт буде так само «100% PASS» при старому UI.
