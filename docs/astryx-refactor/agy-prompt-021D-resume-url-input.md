# Feature 021D — Виправити ввід URL у консолі оператора

## Симптом
У блоці «Продовжити у відкритій вкладці» поле «URL відкритої вкладки» не приймає:
- клавіатурний ввід;
- вставку (Ctrl+V / context menu).

Селект «Персона» при цьому працює.

## Крок 0 — Синхронізація (на dev-сервері 192.168.3.184)
```bash
cd ~/projects/vydra-swiss-survey
git fetch --all
git pull --ff-only
gitnexus index --update
```

## Крок 1 — Діагностика
1. Знайди компонент, що рендерить поле вводу URL у блоці «Продовжити у відкритій вкладці».
2. Перевір, чи є на ньому `readOnly`, `disabled`, перехоплювачі `onKeyDown`/`onPaste`, що блокують ввід.
3. Перевір стан controlled/uncontrolled — можливий race між `value` і `defaultValue`.
4. Перевір, чи не перекриває поле інший елемент (наприклад, невидимий оверлей).
5. Перевір DevTools Console на помилки під час фокусу/вводу.

## Крок 2 — Виправлення
- Поле має бути повністю редагованим.
- Має підтримувати вставку URL.
- Placeholder: `https://meinungsplatz.ch/...`
- При введенні має оновлюватися стан і кнопка «Продовжити» має активуватися лише при валідному URL.
- Якщо використовується Astryx `Input` — переконайся, що прокидаються всі native events.

## Крок 3 — Верифікаційні гейти

### G1 — Unit/компонентний тест
- Симулюй `userEvent.type(input, "https://meinungsplatz.ch/survey/123")`.
- Перевір, що `input.value` збігається.

### G2 — Ручний тест у браузері (dev 192.168.3.184)
- Клік у поле → введення з клавіатури → значення збігається.
- Ctrl+V URL → значення вставилося.
- Вибір персони → кнопка «Продовжити» активна.

### G3 — Тест у стані агента waiting/running
- Перевір, що поле не блокується, коли агент у стані `waiting_verification` або `running`.

### G4 — Mobile viewport 390×844
- Скріншот фокусу в поле після тапу.
- Перевір, що з'являється клавіатура (емуляція) і введення можливе.

### G5 — E2E потік
- Відкрити консоль → вибрати персону → вставити URL `https://meinungsplatz.ch/...` → натиснути «Продовжити».
- У таймлайні має з'явитися крок `resume` з вказаним URL.

### G6 — UI інваріанти
- `rg '#[0-9a-fA-F]{3,8}' src/ | wc -l == 0`
- `rg 'style=\{\{' src/ | wc -l <= 17`
- `bin/ui_verify.sh` → exit 0

### G7 — Без регресій
- `bin/deploy_verify.sh` на `https://survey.exodus.pp.ua` → exit 0
- Перевір, що Viewport, Telegram queue, conflicts count, auth gate працюють як раніше.
