# /sdd:* slash-команди для vydra-swiss-survey

## Встановлення (Claude Code — перевірено)

Скопіюй директорію `.claude/commands/sdd/` у корінь репозиторію (файли вже в правильній структурі в цьому архіві). Це дасть 5 команд:

- `/sdd:feature <назва> — <опис>` → Шаблон 1
- `/sdd:bugfix <опис проблеми>` → Шаблон 2
- `/sdd:refactor <модуль>` → Шаблон 3
- `/sdd:integration <сервіс>` → Шаблон 4
- `/sdd:teaching <профіль> <host> — <опис>` → Шаблон 5

Команди — проєктні (`.claude/commands/`), тобто закомічені в репо й доступні кожному, хто його клонує, а не тільки тобі особисто.

Кожна команда: (1) читає відповідний Шаблон з `docs/sdd-development-methodology.md` замість того, щоб дублювати його текст — єдине джерело правди, без ризику розходження; (2) явно нагадує про `.specify/constitution.md` і MUST-правила з `AGENTS.md`; (3) вимагає в фінальному звіті конкретні докази виконання (файл:рядок, вивід тестів, вивід `sdd_verify.sh`), а не просто "зроблено".

Тут чесно: я не маю підтверджених даних про те, чи agy взагалі підтримує директорію-конвенцію на кшталт `.claude/commands/` з `$ARGUMENTS`-підстановкою — це специфіка Claude Code, яку я перевірив у документації, а не універсальний стандарт. У проєкту вже є `.agents/skills/sdd-workflow/SKILL.md`, який agy читає (це підтверджено — agy сам його верифікував). Два варіанти, залежно від того, що підтримує agy:

1. **Якщо agy має власний механізм slash/CLI-команд** (перевір його документацію чи конфіг) — портуй ці 5 файлів у той формат, зберігши той самий принцип: команда посилається на `docs/sdd-development-methodology.md`, не дублює текст.
2. **Якщо ні** — найпростіше рішення: попроси agy напряму, наприклад "виконай `/sdd:feature`-еквівалент для Шаблону 1 із описом Х", посилаючись на `.agents/skills/sdd-workflow/SKILL.md`. Це трохи менш зручно, ніж односимвольна команда, але дає той самий результат без необхідності вигадувати підтримку command-системи, якої в agy може не бути.

Перш ніж покладатися на варіант 1 — попроси agy самого підтвердити (тим самим Кроком 0, який він уже застосовував раніше): чи є в нього такий механізм, і де він шукає команди.
