# Специфікація модуля Astryx UI Console (`specs/004-astryx-ui-console`)

> **Специфікація:** `specs/004-astryx-ui-console`  
> **Статус:** Активна специфікація  
> **Базовий файл:** `web/src/screens/ops/SurveyOps.tsx`, `RulesTable.tsx`, `PatternsPanel.tsx`

---

## 1. Функціональні вимоги

### 1.1 Інтерфейс Async-HITL у `SurveyOps.tsx`
- Перемикач режимів: `Live-HITL` та `Асинхронний розбір (Async Triage)`.
- Таблиця інцидентів з фільтром за категоріями тріажу.
- Дії: *"Створити правило"*, *"Вирішено"*, *"Ігнорувати"*.

### 1.2 Бейдж підтверджень у `RulesTable.tsx`
- Відображає окремий бейдж `"Підтверджено: N прогонів"` поруч із сирими значеннями `wins`/`losses`.

### 1.3 Позиційний захист в UI
- При виявленні позиційного селектора в оверрайді виводиться попереджувальне модальне вікно з прапорцем `confirm_positional`.
