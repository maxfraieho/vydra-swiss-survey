# Impeccable Design System Skill

This skill provides authoritative visual design guidance for Astryx UI components based on `DESIGN.md` and `PRODUCT.md`.

## Core Principles
1. **Rich Aesthetics & WOW Factor:** Dark mode glassmorphism (`backdrop-filter: blur(12px)`), curated HSL colors, smooth 0.2s transitions.
2. **Dynamic UI:** Hover effects, active state micro-animations, clear status pill badges (`active`, `waiting_captcha`, `shadow`).
3. **Typography:** Inter sans-serif for UI, JetBrains Mono for logs/selectors.
